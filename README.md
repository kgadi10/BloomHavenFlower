# Project Overview

Bloom Haven Flowers is a fictional florist business website developed as part of the Web Development Portfolio of Evidence (POE).

The purpose of this project is to create a functional, responsive, and visually appealing website that allows customers to learn about the organisation, view available floral products, submit enquiries, and access contact information.

The website focuses on providing an easy-to-use online platform that improves customer communication and promotes the organisation’s products and services.

---

# Website Goals and Objectives

The main objectives of the website are:

- Create an online presence for Bloom Haven Flowers.
- Showcase available floral products and services.
- Allow customers to submit enquiries.
- Improve communication between customers and the organisation.
- Provide clear information about the business.

---

# Responsive Design

Responsive design was implemented using:

- Relative units
- CSS Grid
- Flexible layouts
- Media queries
- Desktop, tablet and mobile breakpoints

The main breakpoints are:

- Desktop: Above 900px
- Tablet: 600px - 900px
- Mobile: Below 600px

The product grid changes from two columns to one column on mobile
devices.

The feature grid also changes to a single-column layout on smaller screens.

---

# Responsive Images

Product images use responsive CSS sizing to ensure that images
fit within their containers.

The images also use the HTML `loading="lazy"` attribute to improve
page loading performance.

---

# Form Functionality and Validation

The Enquiry page contains:

- Full name
- Email address
- Phone number
- Flower arrangement
- Event date
- Customer message

JavaScript validates the submitted information before providing
a response to the user.

The Contact page contains:

- Full name
- Email address
- Phone number
- Message type
- Full message

After validation, the contact information is compiled into a
`mailto:` link addressed to Bloom Haven Flowers.
