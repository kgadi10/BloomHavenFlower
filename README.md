# Project Overview

Bloom Haven Flowers is a fictional florist business website developed as part of the Web Development Portfolio of Evidence (POE).

The purpose of this project is to create a functional, responsive, and visually appealing website that allows customers to learn about the organisation, view available floral products, submit enquiries, and access contact information.

The website focuses on providing an easy-to-use online platform that improves customer communication and promotes the organisation’s products and services.

---

# Website Goals and Objectives

The main objectives of the website are:

- Create an online presence for Bloom Haven Flowers.
- Showcase available floral products and services.
- Allow customers to submit enquiries.
- Improve communication between customers and the organisation.
- Provide clear information about the business.
